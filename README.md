# Garden Observation Journal — GitHub-ready package

The actual website files are at the repository root:

- `index.html`
- `styles.css`
- `app.js`
- `content/`

Upload the **contents of this folder** to the root of your GitHub repository.
Do not upload the enclosing folder as a single nested folder.

After GitHub Pages publishes, the journal URL will be:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

Canvas materials are in `canvas-toolkit/`.
