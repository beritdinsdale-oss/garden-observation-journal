# Garden Observation Journal — Climate Memory handoff update

This paired build displays the Climate Memory + Evidence activity handoff in the same structured format learners used in the activity:

- observation investigated
- each guided climate-data question and selected answer
- optional notes
- final comparison with the original observation
- whether the data shifted the learner’s thinking

Replace the current Garden Journal repository files with the contents of this folder when deploying the paired activity revision. Existing browser-saved journal entries continue to use the same storage key.
