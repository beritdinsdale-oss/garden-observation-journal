Extreme Weather journal update

Upload these four CSV files to the journal repository's journal-app/content/ folder:
- settings.csv
- sections.csv
- items.csv
- canvas-links.csv

This update preserves the existing section_id and item_id values so previously saved browser entries remain connected.

The Weather & Climate journal entry now mirrors the Extreme Weather Roadmap:
1. Choose a locally relevant extreme-weather hazard.
2. Examine credible local/regional evidence.
3. Distinguish an event from evidence about future frequency/severity.
4. Judge how certain the future trend is.
5. Decide whether to make it a priority, build in flexibility, or stay aware for now.
