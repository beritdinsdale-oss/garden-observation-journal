Garden Journal handoff receiver

Replace the ROOT app.js in garden-observation-journal with this app.js.
The included styles.css is the same integrated subheading version and may also replace
the current root styles.css if needed.

Do NOT replace the content/ folder.

When opened from the updated Climate Memory + Evidence interview activity, the journal:
1. Reads the transferred observation, evidence finding, and comparison.
2. Saves them into the Module 2 > Climate Memory + Evidence fields.
3. Opens Module 2 automatically.
4. Removes the transfer information from the browser address immediately.

Mapped journal fields:
- memory-observation
- memory-data
- memory-supported / memory-mixed / memory-unclear

The final "What surprised me, or what do I still wonder?" field remains intentionally
blank because learners did not answer that question in the activity.
