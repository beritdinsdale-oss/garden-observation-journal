# Accessibility and Privacy

## Accessibility features

- Semantic headings, labels, fieldsets, and legends
- Keyboard-operable navigation and controls
- Visible focus indicators
- Responsive layout
- Text-based alternatives to icons
- No timed interactions
- Print-friendly complete journal
- Status messages announced through an ARIA live region

## Privacy

Entries are saved in browser localStorage. They are not transmitted to Canvas, GitHub, or the instructor.

Learners should download a backup when:
- switching devices or browsers,
- clearing browser data,
- using a shared or public computer,
- or wanting an extra copy.

Photos can consume browser storage quickly. The app compresses them, but learners should still use photos selectively.
